# BLOOMRA Employee Assessment Portal

A simple, responsive web-based employee examination management system developed for BLOOMRA.

The platform allows employees to log in using their name and department, attend department-specific multiple-choice examinations, and view their results after submission.

Administrators can access a dashboard to monitor employee performance, review examination results, and export assessment records.

## Features
- Employee login with name and department
- Department-wise examination system
- Multiple-choice questions (MCQs)
- Automatic score calculation
- Instant result display
- Admin dashboard
- Employee performance tracking
- CSV result export
- Browser-based local data storage

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Type
Frontend-based employee assessment management system.

**Note:** This version uses browser local storage. Results are available only in the same browser and on the same computer.
